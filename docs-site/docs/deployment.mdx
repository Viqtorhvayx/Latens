# Deployment

Every contract listed below is deployed and source-verified on its network's block
explorer, so the code described throughout these docs can be read directly rather than
taken on trust. This table is generated from the same `deployment.json` the app itself
reads its contract addresses from, so it can never drift out of sync with what is actually
live.
