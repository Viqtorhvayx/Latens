# Deployment

Every contract listed below is deployed and source-verified on its network's block
explorer, so the code described throughout these docs can be read directly rather than
taken on trust. This table is generated from the same `deployment.json` the app itself
reads its contract addresses from, so it can never drift out of sync with what is actually
live.

Latens is built for Horizen, the EVM-native L3 that settles to Base, and the table below is
the live deployment on Horizen's own testnet (chain ID 2651420), not a stand-in on a
generic EVM chain. Every address links to Horizen's own block explorer, which verifies
contracts through Blockscout's own API rather than Etherscan's, which is what Horizen's own
deployment documentation specifies.
