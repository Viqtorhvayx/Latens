# Deployment

Every contract listed below is deployed and source-verified on its network's block
explorer, so the code described throughout these docs can be read directly rather than
taken on trust. This table is generated from the same `deployment.json` the app itself
reads its contract addresses from, so it can never drift out of sync with what is actually
live.

Latens is built for Horizen, the EVM-native L3 that settles to Base. Hardhat is already
configured with a `horizenTestnet` network for exactly that target, and the table below is
currently on Ethereum Sepolia rather than Horizen itself, purely because Horizen's own
public testnet RPC endpoint isn't published yet; the contracts themselves are unmodified
and ready to redeploy the moment it is, since Base (and by extension Horizen) already
supports the same Cancun EVM target this project compiles against.
